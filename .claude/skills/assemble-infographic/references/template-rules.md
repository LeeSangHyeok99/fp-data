# Four Pillars Graph H 1080 Template

## 고정 자산

- 템플릿: `../assets/four-pillars-graph-h-1080.svg`
- 캔버스: 1920 x 1080
- 배경: `#141414`
- 배경 그래픽, 중앙 Four Pillars 워터마크, 상단 심볼, 우측 하단 로고는 유지한다

## 동적 영역

| 영역 | 위치 및 처리 |
|---|---|
| Title | 상단 중앙, 기존 `Title_1 line` path를 교체 |
| Subtitle | 본문 왼쪽 상단, 기존 `Title 1 line_2` path를 교체. 왼쪽 끝을 Y축 눈금 라벨의 실제 왼쪽 끝과 정렬 |
| Legend | 넓고 낮은 차트는 차트 아래 중앙, 우측 여백을 확보할 수 있는 차트는 오른쪽. 차트 위 배치 금지 |
| Chart | 아래형은 `(160, 290, 1600, 540)`, 범례는 `y=850`부터. 오른쪽형은 최대 `(160, 300, 1320, 630)` 안에서 원본 비율에 맞춘다 |
| Source | 좌측 하단. `Source` 라벨과 실제 출처 값을 분리 |
| Date | 하단 중앙. `Date as of` 라벨과 데이터 종료일 값을 분리 |
| Note | 값이 있을 때만 Source 위에 표시 |

## 불변 조건

- 최종 SVG와 PNG의 파일명은 인포그래픽에서 가장 크게 표시되는 Title 문구로 지정한다. 내부 차트 슬러그를 그대로 쓰지 않으며 파일명 끝의 문장부호는 생략한다.
- 차트를 강제로 늘이거나 찌그러뜨리지 않는다.
- 차트의 제목, 범례, Source를 템플릿과 중복해서 넣지 않는다. 범례는 조립 단계에서만 만든다.
- 원본 시리즈가 5개를 넘으면 표시 기간 합계 상위 5개와 나머지를 시점별로 합산한 `Others`로 차트를 다시 그린다. 범례만 합치지 않는다.
- 범례는 최대 6개다. 일반 순서에서는 `Others`를 마지막에 두고, 누적 차트의 역순 범례에서는 첫 번째에 둔다.
- 차트 SVG의 ID는 템플릿 ID와 충돌하지 않도록 prefix를 붙인다.
- Source와 날짜를 파일명이나 이미지에서 추측하지 않는다.
- Date as of에는 데이터의 마지막 날짜만 `Mon DD, YYYY`로 표시한다. 시작일이나 기간 범위를 넣지 않는다.
- 템플릿의 폰트와 폰트 크기를 변경하지 않는다. 모든 동적 텍스트는 Pretendard를 유지한다.
- Title, Subtitle, Legend는 모든 단어의 첫 글자를 대문자로 변환한다. 단어의 나머지 글자는 원래 대소문자를 유지해 브랜드, 티커, 수치 표기를 훼손하지 않는다.
- 고정 크기는 Title 50px, Subtitle 38px, 범례 28px, Note/Source/Date as of 라벨 22px, 각 내용 28px이다. Subtitle 굵기는 Pretendard Medium 500으로 고정한다.
- 인포그래픽용 차트의 X축·Y축 눈금 라벨은 모두 16px로 유지한다.
- 글자가 영역을 넘으면 폰트 크기를 줄이지 않고 줄바꿈 또는 배치 조정으로 해결한다.
- Title 줄바꿈은 문법적 의미 단위를 먼저 보존하고, 그 안에서 줄 길이를 가능한 한 균형 있게 맞춘다. 전치사는 뒤의 목적어와 같은 줄에 두어 전치사구를 보존하고, 관사와 접속사는 줄 끝에 홀로 남기지 않는다. 월과 연도, 수치와 단위, 고유명사를 분리하거나 마지막 줄에 한 단어만 남기지 않는다.
- Subtitle은 차트 SVG의 `ytick_*` 그룹에서 계산한 Y축 눈금 라벨의 최소 X좌표에 맞춘다. 오른쪽형과 아래형 모두 적용한다.
- 범례 기호는 원본 자산 크기를 유지한다. 사각형은 24x24px, 실선은 48x8px, 점선은 10px 두께다. 기호와 범례 글자를 확대하거나 축소하지 않는다.
- 아이콘과 텍스트가 나란히 배치될 때 두 요소의 세로 중심을 동일한 좌표에 맞춘다. 텍스트 baseline을 아이콘 하단에 맞추지 않는다.
- Figma가 `dominant-baseline`을 일관되게 해석하지 않으므로 범례 텍스트 정렬에 해당 속성을 사용하지 않는다. Pretendard의 cap-height로 계산한 명시적 Y축 baseline을 사용한다.
- 최종 SVG는 외부 이미지 링크 없이 단독 렌더링되어야 한다.
- Source, Date as of, Four Pillars 로고는 고정 자산이다. 템플릿 원본의 그룹 위치와 도형 좌표를 절대 변경하지 않는다. Source와 Date는 기존 값 outline만 동적 텍스트로 교체하고 라벨과 구분선은 원본 path를 보존한다.

## 범례 자산 매핑

| 차트 표현 | 기호 | 자산 |
|---|---|---|
| 일반 실선 라인 | 얇은 둥근 막대 | `../assets/legend-line.svg` |
| 점선 또는 파선 라인 | 점선 | `../assets/legend-dashed.svg` |
| 막대, 영역 및 나머지 표현 | 둥근 사각형 | `../assets/legend-square.svg` |

자산은 기호 형태의 기준이다. 스크립트가 실제 시리즈 색상과 라벨을 적용해 외부 링크 없이 다시 그린다.

## 범례 배치

- 누적 막대와 누적 영역 차트의 범례는 스택의 위쪽 레이어부터 아래쪽 레이어 순으로 읽히게 배치한다. 즉 차트의 누적 시리즈 순서를 뒤집어 범례의 위에서 아래 순서로 사용한다.
- `auto`: 차트 SVG의 가로세로 비율이 1.8 이상이면 아래형, 그보다 작으면 오른쪽형을 사용한다.
- 아래형: 차트를 먼저 배치하고 범례를 차트 하단 아래에 가로로 놓는다. 필요하면 줄바꿈하되 범례가 Footer 영역에 들어가면 안 된다.
- 오른쪽형: SVG 슬롯이 아니라 실제 플롯 영역을 나타내는 가장 큰 `clipPath` 사각형을 Y축 범위로 사용한다. 범례 첫 항목의 상단을 플롯 상단에 맞춘다.
- 오른쪽형에서 항목이 6개면 첫 항목 상단부터 마지막 항목 하단까지 실제 Y축 길이 안에 고르게 분산한다. 범례가 Y축 범위를 넘어가면 안 된다.
- 오른쪽형에서 항목이 5개 이하면 첫 항목을 차트 최상단에 놓고 항목 사이 빈 간격을 약 50px로 둔다.
- 자동 판단이 실제 여백과 맞지 않으면 렌더링을 확인한 뒤 `right` 또는 `bottom`을 명시한다.

## 시각 검수 기준

- Title은 상단 심볼과 겹치지 않는다.
- Title의 줄바꿈이 의미 단위를 보존하고 각 줄의 길이가 시각적으로 균형을 이룬다.
- Subtitle의 왼쪽 끝과 Y축 눈금 라벨의 실제 왼쪽 끝이 정렬된다.
- Subtitle 아래에서 차트가 시작한다.
- 아래형 범례는 Subtitle, 차트, 범례 순서로 배치되고 서로 겹치지 않는다.
- 오른쪽 범례는 차트의 오른쪽에 있고 첫 항목의 상단과 마지막 항목의 하단이 실제 Y축 범위 안에 맞는다.
- 범례의 기호와 색상이 실제 시리즈 표현과 일치한다.
- 범례 아이콘과 글자가 세로 가운데 정렬된다.
- 차트의 축 틱과 주석이 슬롯 경계에서 잘리지 않는다.
- X축과 Y축 눈금 라벨의 크기가 동일하며 16px로 읽기 쉽게 표시된다.
- Footer는 y=960 아래에만 머물고 차트와 겹치지 않는다.
- Source 구분선은 `x=82`, Date as of 구분선은 `x=1051`, Four Pillars 로고는 원본 그룹 좌표를 유지한다.
- Source와 날짜는 1920px 원본 및 960px 축소본에서 읽을 수 있어야 한다.
