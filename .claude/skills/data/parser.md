# Data Parser

`outputs/data/`의 원본 또는 `*_raw.*` 입력을 차트가 읽을 수 있는 표 형식으로
정규화한다.

- CSV는 UTF-8을 기본으로 읽고 원래 열 이름을 보존한다.
- 날짜는 파싱 후 ISO 8601로 저장하며 시간대가 있으면 함께 보존한다.
- 숫자의 통화 기호, 천 단위 구분자, 백분율은 명시적으로 변환한다.
- 결측치와 중복 행의 처리 방법을 결과 메타데이터에 기록한다.
- 원본 파일을 덮어쓰지 않고 `outputs/data/<name>_processed.*`에 저장한다.
- 스키마 불일치는 `PARSE_ERROR`로 반환하고 문제가 된 열과 행을 알린다.
